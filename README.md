# QR Attendance System

A Flask-based QR code attendance system for classrooms. Students scan QR codes with their phones to log attendance in real-time.

## Features

- QR code generation per student
- Student attendance marking via phone scan
- Admin dashboard with real-time attendance view
- CSV/JSON export
- Student list management

## Tech Stack

- Python Flask
- JSON-based storage
- QR code generation
- Jinja2 templates

## Setup

```bash
pip install flask
python3 app.py
```

Open `http://localhost:5000` in your browser.
